## Requirement
Every external modality (vision, file input, image generation, speech to text, text to speech) is optional, OFF by default
(ADR-0024) and capability-gated; raw audio leaves only under explicit provider and tenant policy and only when no local
transcript or local STT exists; external TTS receives only verified response text; files go by scoped expiring reference, approved
only, application-private files with explicit egress permission; generated media is stored locally first and returned as an AlixAI
reference; provider Markdown, HTML, charts and blocks are validated before a host renders them; retention is disclosed. Gate and
validation must add negligible time and no resident cost while external mode is off.

## No-model / deterministic option
All of this task is deterministic code: policy lookups, profile and capability checks, reference resolution, an allowlist of media
types, a sniffing local store, a Markdown rewriter and a JSON-Schema block validator. No model decides any of it. The deterministic
data-minimising choices are also the cheapest ones, and each is the default: a finalised local transcript is used instead of audio
(0 bytes sent), a transformed excerpt instead of a file (bytes of the excerpt only), a reference instead of inline bytes, and the
verified response text instead of anything richer. Chosen; see Decision.

## Decision
The smallest data path that does the job is the default for each modality and the larger one needs an explicit switch:

* **Voice input:** transcript, then local STT, then (only under `raw_audio` at both provider and tenant level, VAD-cut audio, within
  the profile's size limit) external audio. A failing local STT is an error, never a reason to send the audio away: a silent
  switch of destination would be a privacy change nobody approved. Streaming raw audio out is not offered at all.
* **Voice output:** external TTS only for attested verified response text (`Attest` takes the `verify.Outcome`), through the
  data-egress guard. Local TTS stays the offline fallback where installed.
* **Files and images:** reference, never bytes inline; excerpts instead of whole files where the host approves only that.
* **Output:** media goes to the local store first (sniffed, scoped, quota-counted, ephemeral); the host only ever receives the
  AlixAI reference. Markdown is rewritten, not stripped; invalid blocks are dropped and reported.
* **Cheapest hosted tier per modality** (the X-10 rule for each provider): not determinable without calls. The first provider
  profile (X-10, text only) declares no media, so every modality here is refused for it until a profile declares one. The tier
  comparison is X-H02's, using the Meter in `observe.go`, which records calls, bytes sent and received and latency per modality
  and provider.

## Resource impact
Measured, dev box (`go test -bench`, 2,000 iterations):

| Operation | Time | Memory | Allocations |
|---|---|---|---|
| `Admit` (policy read, profile and capability checks, disclosure) | 1.65 µs | 568 B | 6 |
| `Ingest` of a 1 KiB Markdown answer (sanitise to a block) | 234 µs | 101,855 B | 949 |

The gate is about a microsecond and a half against external calls that take hundreds of milliseconds at least, so its overhead is
below any measurement noise of the call. Sanitising is linear in the answer and bounded by the blocks limits (`MaxMarkdownBytes`).
Memory held: one small in-memory map of attested response texts (at most 32 per session, 10-minute lifetime, trimmed on use) and
nothing else; no goroutine, socket, file or timer. Disabled (the default), the package does nothing: no policy read, no
allocation, no outbound traffic; it is also not linked into `cmd/alixai` by this task (the composition root comes later), so the
binary size is unchanged. Storage: generated files use the existing files quota and one-hour ephemeral lifetime. Concurrency is
bounded by the caller and the budget reservation (X-09), not by this package. Power: not measured.

## 4 GB profile impact
Preserves it. Nothing here is resident or always-on, and every external modality is the way a small machine gets voice or vision
without local workers: M4-06 shows the smallest voice stack already peaks at 243 MiB against 248 MiB spare, and no local TTS fits,
so an external TTS or STT under explicit policy is the only voice path that could ever fit the 4 GB profile. The price is money,
latency and data leaving, handled by policy and disclosure, not RAM.
