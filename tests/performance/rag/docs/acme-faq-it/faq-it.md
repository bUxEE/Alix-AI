# Domande frequenti

## Accesso all'account

Se non riesci ad accedere, usa il portale self-service: apri Impostazioni, scegli Sicurezza e seleziona Reimposta password. Il link di reimpostazione scade dopo 30 minuti e può essere usato una sola volta.

## Fatture

Le fatture vengono emesse il primo giorno lavorativo del mese. Scaricale in formato PDF dalla pagina Fatturazione.
