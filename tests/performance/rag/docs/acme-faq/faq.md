# Customer FAQ

## Account access

If you cannot sign in, use the self-service portal: open Settings, choose Security and select Reset password. The reset link expires after 30 minutes and can be used once.

## Invoices

Invoices are issued on the first working day of the month. Download them from the Billing page in PDF format.

## Data export

Administrators can export all workspace data as a ZIP archive from Settings, Export. The export is ready within 15 minutes for workspaces under 5 GB.
