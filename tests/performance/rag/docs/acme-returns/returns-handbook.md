# Returns and warranty handbook

## Return merchandise authorisation

Every return needs a return merchandise authorisation before the parcel is sent. Support issues the authorisation as an RMA number in the format RMA-NNNNN, for example RMA-48213 for the Atlas router returned by Contoso Retail. A parcel that arrives without an RMA number written on the label is refused at the warehouse and sent back at the sender's cost.

The warehouse inspects every returned item within 3 working days of receipt. Items that show water damage or a broken warranty seal are not covered by the warranty.

## Shipping

Orders placed before 14:30 CET ship the same day. Express shipping costs 12 EUR and arrives within 2 working days.
