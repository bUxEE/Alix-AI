# Security FAQ

## Passwords

Passwords must have at least 14 characters. A password expires after 180 days and cannot repeat any of the last 5 passwords.

## Two-factor authentication

Two-factor authentication is mandatory for administrators. Users can register an authenticator app from Settings, Security.

## Reporting incidents

Report a suspected security incident to the security desk within 1 hour. The incident form is available from the Support page.
